# MMH Study Site

Mở `index.html` bằng trình duyệt để sử dụng.

Chức năng:
- Tìm kiếm nội dung
- Lọc theo nguồn SLIDE / ĐÁP ÁN
- Mục lục theo chủ đề
- Thu gọn / mở rộng đáp án
- Chế độ ôn nhanh ngẫu nhiên 20 câu
- Giao diện sáng / tối
- Responsive cho điện thoại

Có thể upload toàn bộ thư mục lên GitHub Pages.
